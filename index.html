详细教程 · 手势与操作

1. 手掌移动转动地球；五指收拢/张开控制缩放。

2. 比耶（食指+中指伸出）保持 0.4 秒 → 流星雨；握拳 → 引力加速；摇滚手势 → 星轨；食指在空中画圈 → 星轨；拇指食指捏合后快速张开 → 脉冲波。

3. 鼠标点击城市进入观察者模式，长按拖拽解除；滚轮缩放。

4. 食指拇指捏合两下进入城市模式，每次摆手切换一个最近重点城市。

5. 五指捏合后轻微摆动两次解除观察者模式。

6. 快捷键：空格暂停自转 · [ ] 灵敏度 · f 航线 · c 摄像头 · r 复位视角 · s 存图 · u 隐藏界面。
